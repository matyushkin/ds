# Издания и блоги по LLM и генеративному ИИ

### English

- [Ahead of AI](https://magazine.sebastianraschka.com/) (Sebastian Raschka) — глубокие разборы LLM-архитектур и методов обучения
- [Simon Willison's Weblog](https://simonwillison.net/) — практические эксперименты с LLM-инструментами и API
- [Lil'Log](https://lilianweng.github.io/) (Lilian Weng, OpenAI) — обзоры по LLM-агентам, RAG, промптингу
- [Latent Space Podcast](https://www.latent.space/) — подкаст с создателями LLM-инструментов и фреймворков
- [Hugging Face Blog](https://huggingface.co/blog) — анонсы моделей, методы fine-tuning, бенчмарки
