# Данные и бенчмарки для MLOps

### English

- [MLPerf](https://mlcommons.org/benchmarks/) (MLCommons) — стандартизированные бенчмарки производительности ML-систем: training, inference
- [Hugging Face Model Cards](https://huggingface.co/docs/hub/model-cards) — стандарт документирования моделей: метрики, ограничения, intended use
- [Google ML Metadata (MLMD)](https://github.com/google/ml-metadata) — отслеживание артефактов и линейджа ML-пайплайнов
